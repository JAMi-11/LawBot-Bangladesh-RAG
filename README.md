# LawBot-Bangladesh-RAG
LawBot is an AI-powered Legal QA system for Bangladeshi law using RAG architecture. Built with LangChain, FAISS, HuggingFace embeddings, &amp; Gemini 2.5 Flash. Developed by Jamiur Rahman, Md. Ahmed Alif, &amp; Mahbubur Rahman Talha to deliver accurate, contextual legal info.
